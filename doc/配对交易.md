# 配对交易

**代码**：[quant/strategy/pairs_trading.py](../quant/strategy/pairs_trading.py) · [quant/strategy/cointegration.py](../quant/strategy/cointegration.py) · [scripts/find_cointegrated_pairs.py](../scripts/find_cointegrated_pairs.py)

## 模块功能

配对交易是最经典的统计套利策略。核心逻辑：

> 找到两只历史价格走势高度相关的股票，当它们的价差（spread）偏离正常范围时，做多低估的一只、做空高估的一只，等待价差回归均值后平仓获利。

与单边做多/做空的区别：配对交易是**市场中性**的——同时持有多头和空头，对冲掉大盘涨跌的系统性风险，只赚取两只股票相对定价误差的钱。

---

## 一、协整是核心前提

### 相关性 ≠ 协整

这是配对交易最容易被误解的地方。两只股票"走势相似"（相关性高）并不代表它们适合做配对交易。

```txt
         相关性高                 协整
    ┌─────────────────┐   ┌─────────────────┐
    │  价格走势相似    │   │  价差长期稳定    │
    │  价差可能发散    │   │  价差均值回归    │
    │  例：茅台与格力  │   │  例：招行与兴业  │
    └─────────────────┘   └─────────────────┘
```

- **相关性**衡量两只股票价格的**方向一致性**，但不保证价差会回归。两只股票相关性高，价差也可能越走越远。
- **协整**要求两只股票的**线性组合（价差）是平稳的**——价差围绕均值波动，偏离后必然回归。

>A 股案例：招商银行（600036）和兴业银行（601166）同属股份制银行，业务结构相似——价格走势高度一致，价差在长期内围绕均值波动，是经典的协整对。

### Engle-Granger 协整检验

`check_cointegration()` 用 statsmodels 的 `coint()` 做 EG 两步法检验，p-value < 0.05 表示两序列协整。

```python
def check_cointegration(price_a, price_b, pvalue_threshold=0.05):
    _, pvalue, _ = coint(price_a, price_b)
    return pvalue < pvalue_threshold
```

**使用方式**：只有协整检验通过了，才应该把这一对股票纳入配对交易候选池。

**注意事项**：

- 协整检验需要足够长的价格历史（至少 1~2 年日线数据），样本太少时统计结果不可靠
- 协整关系不是永恒的——公司基本面变化后，曾经的协整对可能失效
- 同行业配对更容易通过协整检验（业务结构相似），跨行业配对即使统计上协整，经济含义也较弱

## 二、对冲比率

### 直觉

如果 A 股票涨 1% 时 B 股票平均涨 0.8%，那么做多 1 份 A 就需要做空 0.8 份 B 来对冲系统性波动。

### OLS 估计

`hedge_ratio()` 用 OLS 回归 `price_a ~ price_b` 估计对冲比率：

```python
def hedge_ratio(price_a, price_b):
    return np.polyfit(price_b, price_a, 1)[0]
```

这样做的好处：

1. **直观**：用最小的均方误差找到最佳的线性关系
2. **可解释**：$\beta$ 就是对冲比率
3. **简单**：闭式解，计算极快

**回归元顺序**：`polyfit(price_b, price_a)`，因为模型是 `A = β·B + α`，`price_b` 是自变量。顺序反了会导致对冲比率倒挂。

### 对冲比率的时变性

OLS 假设对冲比率在全样本期内恒定——这在现实中很少成立。变化原因：

| 原因 | 举例 |
| :--- | :--- |
| 资本结构变化 | A 增发股票 → 每股价值稀释 |
| 业务结构变化 | B 收购新业务 → 利润结构改变 |
| 行业政策变化 | 银行降息 → 对息差股的影响比例不同 |

## 三、价差与标准化

### 原始价差 vs 标准化价差

原始价差：$\text{spread}_t = A_t - \beta \cdot B_t$

这个价差的量级因股票价格而异——茅台 1500 元 vs 招行 30 元，直接比较没有意义。

标准化 z-score：

$$z_t = \frac{\text{spread}_t - \mu(\text{spread})}{\sigma(\text{spread})}$$

标准化后价差的均值为 0、标准差为 1，可以用固定阈值（如 ±2σ）生成信号，无需针对每对股票单独调参。

### spread() 实现

```python
def spread(price_a, price_b):
    ratio = hedge_ratio(price_a, price_b)
    raw_spread = price_a - ratio * price_b
    return (raw_spread - raw_spread.mean()) / raw_spread.std()
```

**注意**：这里用的 `mean()` 和 `std()` 是全样本的——在回测中有前视偏差。实盘做滚动标准化会更安全：

```python
# 滚动标准化方式（推荐在实盘中使用）
roll_mean = raw_spread.expanding().mean()
roll_std = raw_spread.expanding().std()
zscore = (raw_spread - roll_mean) / roll_std
```

当前代码直接用全样本统计量，适合研究阶段的快速验证。若做样本外回测，需改用滚动窗口。

## 四、交易信号

### 阈值逻辑

`generate_signal()` 用双阈值设计：

```txt
价差状态       z-score         信号    操作
────────────────────────────────────────────────────
价差过高       z > +2.0σ        -1     做空 A、做多 B（价差缩小）
价差回归       |z| < 0.5σ      0      平仓
价差过低       z < -2.0σ        +1     做多 A、做空 B（价差扩大）
```

**入场宽（±2σ）**：

- 确保偏离足够大，均值回归的空间足够覆盖交易成本
- 减少假信号——z 在 ±1σ 之间波动是正常的随机扰动，不应该触发交易

**出场窄（±0.5σ）**：

- 不等价差完全回归到 0 就平仓，锁定大部分利润
- 避免在回归途中反复震荡导致盈利回吐

**信号方向**：

| 条件 | 引擎信号 | 具体操作 |
| :--- | :---: | :--- |
| z < -2（A 太低） | +1 | 做多 A（低估）+ 做空 B |
| z > +2（A 太高） | -1 | 做空 A（高估）+ 做多 B |

### 信号行为

```python
signal = pd.Series(0, index=spread.index)
signal[spread > 2] = -1
signal[spread < -2] = 1
signal[spread.abs() < 0.5] = 0  # 这行必须放在最后，覆盖前两行
```

**注意赋值顺序**：后赋值的条件覆盖先赋值的。绝对值条件的 `abs()` 检查必须放在最后，确保价差回归后先平仓再判断是否反向开仓。

## 五、完整工作流

```txt
Step 1: 筛选候选对
────────────────
同行业股票池（如银行/白酒/家电）
    ↓
两两组合 → EG 协整检验（p < 0.05）
    ↓
残差诊断（ADF 平稳 + 无严重自相关）
    ↓
滚动对冲比率稳定性（CV < 0.2）

Step 2: 实时交易
────────────────
取最新价格 → 计算对冲比率 → 计算 z-score
    ↓
z > +2σ   → 开空仓（做空 A、做多 B）
z < -2σ   → 开多仓（做多 A、做空 B）
|z| < 0.5σ → 平仓
    ↓
等待下一个价格更新
```

### 筛选脚本（`find_cointegrated_pairs.py`）

```txt
同行业候选池
    ↓
两两组合配对
    ↓
Engle-Granger 协整检验（p < 0.05 通过）
    ↓
残差诊断（ADF 平稳 + 无严重自相关）
    ↓
滚动对冲比率稳定性（按 CV 排序）
    ↓
输出高质量协整对列表
```

筛选通过的多维度打分：

| 指标 | 筛选条件 | 含义 |
| :--- | :---: | :--- |
| EG p-value | < 0.05 | 协整关系统计显著 |
| ADF p-value | < 0.05 | 残差平稳 |
| 自相关 | 无 | 残差无自相关，模型完整 |
| 变异系数 CV | 越小越好 | 对冲比率稳定，协整关系可靠 |

## 六、常见误区

### 1. 使用价格而非收益率做协整检验

配对交易建仓在价格上（做多 X 元 A + 做空 Y 元 B），所以协整检验也应该在**价格**上做，而不是在收益率上做。收益率序列本身就是平稳的（收益率通常围绕 0 波动），检验收益率没有意义。

### 2. 忽略交易成本

配对交易是双边交易，一次开仓涉及**两条腿**：

- 买入 A（付佣金）
- 融券卖空 B（付融券利息 + 佣金）

双边摩擦是单边交易的两倍以上。如果 z-score 频繁穿墙（阈值为 2σ 但每天偏离 1.8σ 然后回归），大量的小亏损会被手续费吞噬。

### 3. 没有止损

z-score 达到 2σ 开仓，但如果价差继续走到 4σ、5σ 呢？代码中没有止损逻辑。

实战建议：设置止损位为 `2 × entry_threshold`（即 ±4σ），超过止损无条件平仓——宁可小亏，也不要被一直拖到协整关系失效。

### 4. 融券受限

国内 A 股融券做空并不容易：

- 不是所有股票都可以融券
- 融券成本较高（年化 6%~10%）
- 融券额度有限，大规模资金难以执行

## 七、局限与边界

| 局限 | 影响 | 可能的缓解 |
| :--- | :--- | :--- |
| 只支持两资产 | 不能用于多资产篮子 | 使用 PCA 篮子套利（`pca_basket.py`） |
| 静态对冲比率 | 不适应时变关系 | 使用 Kalman Filter（`kalman_hedge.py`） |
| 全样本标准化有前视偏差 | 回测结果偏乐观 | 改用滚动窗口标准化 |
| 无止损机制 | 极端行情下亏损不可控 | 手动加止损条件 |
| 融券受限 | 做空腿无法执行 | 用股指期货或行业 ETF 替代 |
| 协整关系会失效 | 配对可能"脱钩" | 定期重检，设置失效止损 |
