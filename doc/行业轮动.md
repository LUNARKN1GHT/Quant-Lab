# 行业轮动

**代码**：[quant/sector/rotation.py](../quant/sector/rotation.py) · [quant/sector/loader.py](../quant/sector/loader.py)

## 模块功能

判断当前市场哪些行业处于相对强势阶段，输出超配/低配建议。

行业轮动的逻辑基础：**不同行业在经济周期的不同阶段表现各异**——复苏期金融和工业领涨，过热期能源和材料强势，滞胀期消费防御抗跌，衰退期公用事业稳健。即使无法准确判断经济周期位置，通过追踪行业间的**相对强弱变化**，也能在趋势明确后及时跟随。

## 数据来源：申万一级行业

**`quant/sector/loader.py`**

```txt
akshare.sw_index_first_info()
    → 获取申万一级行业代码列表（31 个行业）

akshare.index_hist_sw(symbol=code, period="day")
    → 每个行业的历史日频收盘价
    → 保存到 data/sectors/{code}.csv
```

**为什么用申万行业而不是中信或 GICS？**

申万行业是 A 股研究中使用最广泛的分类标准，分析师覆盖和行业研报基本以申万为准。使用相同分类可以方便地对比外部研究结论。

**本地缓存**：每个行业一个 CSV 文件，启动时只拉取新增数据。单行业加载失败时跳过（akshare 偶发超时），不中断整体批量加载。

## 核心指标：相对强度（RS）

**`calc_rs()`**

$$RS_{i,t} = \frac{\text{行业 } i \text{ 过去 } N \text{ 日涨幅}}{\text{基准过去 } N \text{ 日涨幅}}$$

```python
sector_ret = sector_close.pct_change(window)    # 行业 N 日涨幅
bench_ret = benchmark.pct_change(window)         # 基准 N 日涨幅
rs = sector_ret.div(bench_ret.replace(0, nan))   # RS = 行业 / 基准
```

| RS 值 | 含义 |
| :---: | :--- |
| RS > 1 | 行业跑赢大盘（相对强势） |
| RS = 1 | 与大盘同步 |
| RS < 1 | 行业跑输大盘（相对弱势） |

**为什么用相对涨幅而不是绝对涨幅？**

大盘整体上涨时，几乎所有行业的绝对涨幅都为正，无法区分强弱。RS 衡量的是"相对于基准多赚了多少"，在牛市和熊市中都有区分度——RS > 1 的行业，即使大盘下跌，它的跌幅也比基准小。

**基准涨幅为 0 的处理**：

当基准在某个窗口内涨幅恰好为 0 时，除法无意义（结果为 inf）。代码用 `.replace(0, float("nan"))` 将此类情况置为 NaN，而非让 inf 污染后续计算。

## RS 动量

**`calc_rs_momentum()`**

RS 水平高说明行业过去跑赢大盘，但不代表这种强势正在加速。**RS 动量**衡量的是最近 `lookback` 日内 RS 序列的变化趋势：

```python
slope = np.polyfit(range(len(y)), y, 1)[0]  # RS 序列的线性回归斜率
```

- 斜率 > 0 且较大：相对强势在加速，行业轮动的右侧跟随信号
- 斜率 < 0：RS 开始下行，行业可能处于轮动末尾

**数据点保护**：若最近 `lookback` 日内有效数据少于 `lookback // 2`，该行业的动量置为 NaN，避免用极少数据拟合出噪声斜率。

## 配置建议输出

**`get_suggestions()`**

综合 RS 水平和 RS 动量，用综合排名筛选超配/低配行业：

```txt
综合排名 = (RS 排名 + RS 动量排名) / 2

前 top_n 名 → 超配 ▲
后 top_n 名 → 低配 ▼
其余        → 中性
```

**为什么把 RS 水平和 RS 动量各占一半？**

只看 RS 水平会追高——强势行业往往已经涨幅较大，性价比下降。只看动量会在震荡中频繁切换信号。两者综合，选出的是"当前相对强势、且强势仍在加速"的行业，兼顾了趋势的存在性和持续性。

## 局限与边界

- **趋势跟随的滞后性**：RS 是基于历史价格计算的，行业拐点时信号会明显滞后。行业见顶后，RS 仍可能为高值维持一段时间
- **窗口选择的主观性**：RS 的 `window=20`（约一个月）和动量的 `lookback=20` 是经验值。不同窗口对应不同的持仓周期——短窗口信号多但噪声大，长窗口平滑但滞后
- **不区分经济周期驱动还是资金驱动**：行业强势可能来自基本面改善，也可能是游资炒作。RS 无法区分原因，只追踪结果
- **A 股行业轮动的特殊性**：A 股行业轮动周期短（通常 1~3 个月），受政策催化影响大，与欧美市场的经典周期规律差异显著
- **申万行业调整的影响**：申万每隔几年会调整行业分类，历史数据的行业归属可能与当前不一致，长样本回测需注意分类口径变化

## 与其他模块的关系

- **与 Regime 的关系**：Regime 判断整体市场牛熊，行业轮动在此基础上决定"在牛市里超配哪个行业"。两者是上下层关系：先看市场整体状态，再做行业配置
- **与宏观因子的关系**：宏观指标（PMI、M2 等）对应特定行业有理论上的领先效应——PMI 上升利好工业和材料，利率上升压制金融估值。行业轮动的 RS 信号可以作为宏观逻辑的价格层面验证
- **Dashboard**：`pages/8_sector_rotation.py` 展示各行业的 RS 热力图、RS 动量排行与当日超配/低配建议
- **脚本**：`scripts/research_sector_rotation.py` 提供更详细的历史回溯分析，包括各行业在不同 Regime 下的平均超额收益
