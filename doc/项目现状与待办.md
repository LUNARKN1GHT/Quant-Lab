## 五、当前节点建议：文档阶段的推进顺序

文档的价值在于"把已经理解的东西固化"——优先写知识密度高、容易遗忘的模块。

### 推荐写作顺序

```txt
第一轮（核心方法论）
  1. 回测引擎           ← 最复杂，前视偏差 / 向量化局限 值得详细记录
  2. 风险指标体系        ← 公式容易混，写清楚各指标的适用场景
  3. 因子 IC 分析        ← 截面回归的直觉，ICIR 的统计意义

第二轮（策略层）
  4. 市场状态判断        ← 控仓决策的核心，规则设计的 trade-off
  5. ML Alpha 策略       ← Walk-forward 的正确姿势，避免 data snooping
  6. 统计套利体系        ← 协整 → OU → Kalman → PCA 的递进，有内在逻辑

第三轮（支撑模块）
  7. 多因子合成          ← 等权 / IC 加权 / PCA 的取舍
  8. 宏观因子接入        ← 宏观-市场传导机制
  9. 行业轮动            ← RS 的计算与行业 ETF 逻辑
```

### 每篇文档建议结构

```txt
## 这个模块解决什么问题？
  （一句话：为什么需要它，不做会怎样）

## 核心概念
  （关键术语 + 直觉解释，不是公式堆砌）

## 实现要点
  （代码里最容易踩坑 / 最值得注意的地方）

## 局限与边界
  （这个模块做不到什么，或在什么场景下会失效）

## 与其他模块的关系
  （在整体系统中的位置）
```
