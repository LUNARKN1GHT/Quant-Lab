## 现状诊断

### Dashboard 重叠分析

当前 `dashboard/pages/` 共 11 页，存在三组明显重叠：

| 重叠组 | 现有页面 | 问题 |
| :--- | :--- | :--- |
| 市场环境 | `2_market_state`、`6_sector_rotation`、`7_macro_factors` | 三页内容独立，但 `1_position_advise` 已把摘要全摆出来了，详情页彼此割裂 |
| 因子研究 | `4_factor_analyze`、`5_params_optimize`、`8_factor_research_adv` | 已知因子、参数调优、自主研究三件事散在三页，缺统一入口 |
| 策略对比 | `3_backtest_compare`、`9_stat_arb` | 没有"策略库"统一视角，统计套利结果与多因子回测无法横向对比 |

### 功能缺口

- 首页 `app.py` 只显示四个指标，缺少信号汇总驾驶舱
- `10_my_portfolio` 仅展示流水，没和"建议仓位"对账
- 风险模块（`quant/risk/`）已实现 Brinson、VaR，但 Dashboard 没承接 → ROADMAP 阶段五"策略风险报告"未交付
- 阶段十七"基金风格回归 / 相关性矩阵"暂停
- 仓位输出仍是单一标量，缺组合优化（mean-variance / risk parity）
- 下载脚本散落 5~6 个（`download_*.py`），缺数据健康监控页
