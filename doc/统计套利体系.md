# 统计套利体系

**代码**：[quant/strategy/](../quant/strategy/) 目录下多个模块 · [scripts/find_cointegrated_pairs.py](../scripts/find_cointegrated_pairs.py) · [scripts/research_*.py](../scripts/) 系列研究脚本

## 模块功能

统计套利是量化交易中"市场中性"的核心策略类别，其基本逻辑是：**找到资产之间的长期均衡关系，当短期偏离均衡时建仓，等待均值回归获利**。

本项目实现了从理论到实践的完整统计套利体系：

| 模块 | 功能 | 对应文件 |
| :---: | :--- | :---: |
| 协整检验 | Engle-Granger / Johansen 检验，判断资产间是否存在均衡关系 | `cointegration.py` |
| 配对交易 | 经典两资产配对，基于协整价差的 z-score 生成信号 | `pairs_trading.py` |
| Kalman Filter | 动态估计对冲比率，适应时变的协整关系 | `kalman_hedge.py` |
| OU 过程 | Ornstein-Uhlenbeck 均值回归建模，半衰期指导参数设定 | `ou_process.py` |
| PCA 篮子套利 | 用 PCA 提取板块共同因子，对个股特质残差做均值回归 | `pca_basket.py` |
| 市场中性 | Beta / 行业中性化组合构建，剥离系统性风险暴露 | `market_neutral.py` |
| 策略对比 | 统一框架对比多个策略的 Sharpe / 回撤等指标 | `compare.py` |

## 一、协整理论（Cointegration）

**代码**：[quant/strategy/cointegration.py](../quant/strategy/cointegration.py) · [scripts/find_cointegrated_pairs.py](../scripts/find_cointegrated_pairs.py) · [scripts/research_cointegration.py](../scripts/research_cointegration.py)

### 核心概念

协整是统计套利的理论基础。直观理解：

> 两个时间序列各自是随机游走（非平稳），但它们的线性组合是平稳的——这个线性组合就是**价差**，价差会在均值附近波动。

```txt
股票A价格 ──┐
            ├── 线性组合 → 平稳价差（均值回归）
股票B价格 ──┘
```

**为什么要协整？**

两只股票若协整，它们之间存在长期的均衡关系，短期偏离会被市场力量拉回。这意味着：

- 价差不会无限发散（有界）
- 偏离后大概率回归（可预测）
- 对冲比率在统计上有意义（非虚假回归）

---

### Engle-Granger 两步法

**`engle_granger()`**

步骤：

1. **第一步**：OLS 回归 `price_a = β × price_b + α + ε`，得到对冲比率 `β` 和残差 `ε`
2. **第二步**：对残差做 ADF 单位根检验。残差平稳 → 两序列协整

**三个关键输出**：

| 输出 | 意义 |
| --- | --- |
| `hedge_ratio` | 对冲比率（需要卖空多少份 B 来对冲一份 A） |
| `pvalue` | 协整检验 p-value，< 0.05 视为协整 |
| `residual` | 协整残差，即对冲后的价差 |

**ADF 检验的直觉**：

ADF 检验的原假设是"序列存在单位根（非平稳）"。如果 ADF p-value < 0.05，拒绝原假设，认为残差平稳。

```txt
              ┌── 平稳（p < 0.05）→ 协整，可以做配对交易
协整残差 ────┤
              └── 非平稳（p >= 0.05）→ 不协整，配对无效
```

---

### Johansen 检验

**`johansen()`**

EG 只能处理两个变量、一个协整关系。Johansen 基于 VAR 模型，能同时：

1. 检测**多个**协整关系的数量
2. 适用于多资产场景（3只以上股票）

输出两个统计量：

| 统计量 | 作用 |
| --- | --- |
| **Trace（迹统计量）** | 检验 H0: 协整关系数 ≤ r vs H1: ≥ r+1 |
| **Max Eigenvalue（最大特征值）** | 检验 H0: 协整关系数 = r vs H1: = r+1 |

若 Trace 统计量 > 95% 临界值，拒绝当前 H0，认为至少存在 r+1 个协整关系。

**EG vs Johansen 的选择**：

| 场景 | 推荐方法 |
| :--- | :--- |
| 仅两资产配对 | EG（简单、快速、够用） |
| 三只以上篮子 | Johansen（多变量检验） |
| 需要协整向量估计 | EG 可直接给出对冲比率 |

> 代码中对 EG 和 Johansen 都做了封装，`research_cointegration.py` 可以对比两种检验的结果一致性。

---

### 残差诊断

`residual_diagnostics()`

找到协整对只是第一步，残差的**质量**直接影响策略表现。四个诊断维度：

#### **1. ADF 平稳性检验**

残差必须平稳，这是协整的前提。

#### **2. Ljung-Box 自相关检验**

```txt
H0: 残差无自相关
H1: 残差有自相关（残差中存在未被模型捕捉的模式）
```

若残差有显著自相关，说明对冲模型存在系统偏差——可能是协整关系不是线性的，或存在滞后效应。

#### **3. Durbin-Watson 统计量**

DW 衡量一阶自相关，范围 [0, 4]：

| DW 值 | 含义 |
| :---: | :--- |
| ≈ 2 | 无自相关（理想） |
| < 1 | 正自相关（严重） |
| > 3 | 负自相关（罕见） |

> DW 只测一阶自相关，Ljung-Box 测多阶——两者互补，不是替代关系。

---

### 滚动对冲比率

**`rolling_hedge_ratio()`**

协整关系不是永恒的。股票的商业模式、资本结构会随时间变化，对冲比率也可能漂移。

滚动 OLS 用固定窗口（如 120 天）每天重新估计对冲比率，观察其稳定性：

```txt
         静态 OLS：一根 β 贯穿全样本
         ─────────────────────────────────
         β = 1.2  （固定值）

         滚动 OLS：β_t 每天变化
         ─────────────────────────────────
         β_t:  1.18 → 1.21 → 1.19 → 1.25 → 1.22
```

**变异系数（CV）**：`CV = σ(β) / |mean(β)|`，衡量对冲比率稳定性。

- CV < 0.1：高度稳定
- CV 0.1 ~ 0.2：一般
- CV > 0.3：不稳定，协整关系可能已失效

实战中，**动态对冲比率（Kalman Filter / 滚动 OLS）通常优于静态 OLS**，因为金融市场的关系是时变的。

---

### 配对筛选流程（`find_cointegrated_pairs.py`）

```txt
同行业候选池（如银行/白酒/家电）
    ↓
两两组合配对
    ↓
Engle-Granger 协整检验（p < 0.05 通过）
    ↓
残差诊断（ADF 平稳 + 无严重自相关）
    ↓
滚动对冲比率稳定性（按 CV 排序）
    ↓
输出高质量协整对列表
```

**为什么限制在同行业？**

跨行业配对（银行 vs 白酒）可能因为宏观因素而出现统计上的伪协整——它们在样本内看起来平稳，但样本外的经济关系可能完全不同。同行业公司的业务结构相似，协整关系的经济含义更清晰。

## 二、配对交易（Pairs Trading）

**代码**：[quant/strategy/pairs_trading.py](../quant/strategy/pairs_trading.py)

### 整体流程

```txt
协整检验通过
    ↓
计算对冲比率 β（OLS）
    ↓
计算标准化价差 z-score
    ↓
z > +2σ → 做空价差（做多B、做空A）
z < -2σ → 做多价差（做多A、做空B）
z 回归 ±0.5σ 以内 → 平仓
```

### 关键函数

**`hedge_ratio()`**

```python
def hedge_ratio(price_a, price_b):
    return np.polyfit(price_b, price_a, 1)[0]
```

用 OLS 拟合 `price_a = β × price_b + α`，β 即对冲比率。注意这里是 `polyfit(price_b, price_a)`，因为模型是 `A ~ B`，回归元的顺序不能搞反。

**`spread()`**

```python
raw_spread = price_a - ratio * price_b
zscore = (raw_spread - mean) / std
```

标准化后价差均值为 0、标准差为 1，这样可以用固定的 z-score 阈值（±2σ）生成信号，无需针对每对股票单独调参。

**为什么标准化？**

不同股票对的价格绝对值差异巨大（茅台 1500 vs 招行 30），原始价差的量级不同无法统一设阈值。标准化后量纲统一为"偏离均值的标准差数"。

**`generate_signal()`**

| 信号 | 条件 | 操作 |
| :---: | :--- | :--- |
| +1 | z < -2 | A 被低估，B 被高估 → 做多 A、做空 B |
| -1 | z > +2 | A 被高估，B 被低估 → 做空 A、做多 B |
| 0 | \|z\| < 0.5 | 价差已回归，平仓 |

**入场 vs 平仓阈值不一样**：入场 2σ（等待偏离足够大才建仓，减少频繁交易），平仓 0.5σ（不等完全回归均值，有利润就止盈一部分，避免回归途中反复震荡）。

### 局限

- OLS 假设对冲比率恒定——现实中很少成立，这是引入 Kalman Filter 的主要原因
- 仅支持两只股票配对，不支持多资产篮子
- 未考虑交易成本对信号频率的影响（高频信号+高成本 = 亏损）

## 三、Kalman Filter 动态对冲

**代码**：[quant/strategy/kalman_hedge.py](../quant/strategy/kalman_hedge.py) · [scripts/research_kalman_hedge.py](../scripts/research_kalman_hedge.py)

### 为什么需要 KF？

静态 OLS 用一个 β 贯穿全样本，但在现实中：

- 公司的资本结构变化（增发/回购）改变股票间关系
- 行业政策变化改变估值逻辑
- 市场微观结构演变

KF 把对冲比率建模为**随机游走**，每天用新观测值更新估计：

```txt
状态方程：β_{t+1} = β_t + η_t     （对冲比率缓慢漂移）
观测方程：price_a_t = β_t × price_b_t + α_t + ε_t  （市场价格观测）
```

### Kalman Filter 流程

**`fit_kalman()`**

每步迭代：

```txt
预测步：
  β_pred = β               （状态预测不变）
  P_pred = P + Q            （不确定性增加）

更新步：
  innovation = price_a - β·price_b - α    （预测误差）
  K = P_pred · H' / (H·P_pred·H' + R)    （Kalman 增益）
  β = β_pred + K · innovation             （状态更新）
  P = (I - K·H) · P_pred                 （不确定性缩小）
```

**Q 和 R 的平衡**：

| 参数 | 含义 | 值越大 |
| :---: | :--- | :--- |
| Q（过程噪声） | β 漂移速度 | 跟踪越快，但噪声越多 |
| R（观测噪声） | 价格观测误差 | 越不相信新观测，β 越平滑 |

`delta` 参数控制 Q 的大小。默认 `delta = 1e-4`，适合日线级别的缓慢漂移。高频策略需要更大的 delta。

**热启动**：前 20 期用 OLS 初始化，避免 KF 初始收敛期的抖动。

---

### 三种方法的对比

| 方法 | 对冲比率 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| 静态 OLS | 恒定一根线 | 简单、可解释 | 无法适应市场变化 |
| 滚动 OLS | 窗口内等权更新 | 适应中等程度变化 | 窗口选择主观，超参数敏感 |
| Kalman Filter | 贝叶斯逐日更新 | 最优权重更新，自适应 | 实现复杂，有超参数 |

**实测结论（来自 `research_kalman_hedge.py`）**：

通常 KF 的价差 ADF p-value 更小（更平稳），半衰期更短（回归更快）。KF 的 z-score 信号更灵敏，在小幅偏离时就能捕捉到交易机会，但也可能增加噪声交易。

## 四、OU 过程建模

**代码**：[quant/strategy/ou_process.py](../quant/strategy/ou_process.py) · [scripts/research_ou_process.py](../scripts/research_ou_process.py)

### OU 过程简介

Ornstein-Uhlenbeck 过程是**带均值回归的随机过程**，是配对交易价差的自然模型：

$$dX_t = \theta (\mu - X_t)dt + \sigma dW_t$$

| 符号 | 含义 | 直觉 |
| :---: | :--- | :--- |
| $\theta$ | 均值回归速度 | 越大，价差回归越快 |
| $\mu$ | 长期均值 | 价差最终回归的目标 |
| $\sigma$ | 波动率 | 随机扰动的大小 |

### 参数估计

**`fit_ou()`**

将 OU 离散化后等价于 AR(1) 模型：

$$X_{t+1} = a + b \cdot X_t + \varepsilon$$

其中：

- $b = 1 - \theta \Delta t$ → $\theta = (1 - b) / \Delta t$
- $a = \theta \mu \Delta t$ → $\mu = a / \theta \Delta t$

用 OLS 拟合 AR(1)，映射回 OU 参数。

### 半衰期（Half-Life）

半衰期是价差偏离均值后**回归一半**所需的预期时间：

$$t_{1/2} = \frac{\ln 2}{\theta}$$

- $t_{1/2} = 5$ 天：价差偏离后约 5 天回归一半，适合短线交易
- $t_{1/2} = 60$ 天：回归极慢，配对交易可能需要持有数月
- $t_{1/2} = \infty$（$\theta \approx 0$）：没有均值回归，不适合套利

**基于半衰期的阈值建议（`entry_exit_thresholds()`）**：

| 半衰期 | 策略特征 | 建议入场阈值 | 建议出场阈值 |
| :---: | :--- | :---: | :---: |
| < 5 天 | 回归极快 | ±1.5σ | 0.3σ |
| 5 ~ 15 天 | 正常 | ±2.0σ | 0.5σ |
| 15 ~ 30 天 | 回归较慢 | ±2.5σ | 0.75σ |
| > 30 天 | 回归极慢 | ±3.0σ | 1.0σ |

逻辑：回归越快，可以越激进（窄阈值，更多交易机会）；回归越慢，就需要更大的偏离来确保回归空间足够。

### 滚动 OU

**`rolling_ou()`**

OU 参数本身也是时变的。滚动拟合（252 日窗口）可以观察：

- $\theta$ 是否长期为正（均值回归是否持续存在）
- 半衰期是否急剧增大（协整关系可能正在失效）

若半衰期从 5 天突然飙升至 100 天以上，应暂停该配对交易，等待协整关系重新确认。

## 五、PCA 篮子套利

**代码**：[quant/strategy/pca_basket.py](../quant/strategy/pca_basket.py) · [scripts/research_pca_basket.py](../scripts/research_pca_basket.py)

### 动机

配对交易只支持两只股票，但板块内的股票通常有多个（银行板块 10+ 只、白酒板块 8+ 只）。PCA 篮子套利将配对交易扩展到**多资产**场景：

```txt
板块内所有股票收益率
    ↓
PCA 分解：
  共同因子（PC1）：驱动板块整体走势的系统性部分
  特质残差 ε_i：   个股特有的局部偏离
    ↓
当 ε_i 偏离历史均值过大 → 做多低估股、做空高估股
```

### 核心逻辑

每只股票的收益率可以分解为：

$$r_i = \beta_i \cdot F_1 + \varepsilon_i$$

- $F_1$：第一主成分（板块共同因子），解释板块大部分收益率变动
- $\beta_i$：股票 i 对共同因子的载荷（敏感度）
- $\varepsilon_i$：特质残差，是统计套利的信号来源

PCA 的作用是提取板块共同因子。残差 $\varepsilon_i$ 代表了该股票**相对于板块的异常表现**——如果残差太大，说明该股票相对于板块被高估或低估。

**为什么 PCA 比简单等权板块指数更好？**

等权板块指数对每只股票权重相同，PCA 自动根据历史协方差结构分配载荷——对板块贡献更大的股票有更高的 $\beta_i$，残差更准确地反映个股的特质波动。

---

### 滚动 PCA 避免前视偏差

**`rolling_pca_residuals()`**

关键设计：第 t 日只使用 `[t-window, t-1]` 的历史数据拟合 PCA，再投影第 t 日的收益率。

```txt
训练窗口（60天）        预测日
[xxxxxxxxxxxxxxxxxxxx]   t
  ↑ 第 t 日只能用到 t-1 日的数据拟合 PCA
```

这样确保残差是**真实样本外**的——如果全样本一次 PCA，第 t 日的残差包含了未来信息。

**PCA 中 NaN 处理**：某只股票如果上市不满窗口期，或近期退市，当日不参与 PCA 拟合。`fillna(0)` 仅在投影当日数据时使用，训练数据中已 `.dropna(axis=1)` 过滤。

---

### 信号生成

**`pca_zscore()` → `basket_signal()`**

```txt
特质残差 ε_{i,t}
    ↓
滚动标准化 z-score（20 日窗口）
    ↓
z < -1.5 → 做多（残差太低，被低估）
z > +1.5 → 做空（残差太高，被高估）
|z| < 0.5 → 平仓
```

**截面标准化**：每日对所有股票的残差做截面均值和标准差标准化，控制截面上的信号分布一致性。

---

## 六、市场中性组合

**代码**：[quant/strategy/market_neutral.py](../quant/strategy/market_neutral.py) · [scripts/research_market_neutral.py](../scripts/research_market_neutral.py)

### 概念

市场中性策略的目标是**剥离掉系统性风险（Beta）**，只保留选股的 Alpha。

```txt
组合收益 = Alpha + Beta × 市场收益

市场中性 → Beta ≈ 0 → 组合收益 ≈ Alpha
```

在统计套利框架下，市场中性是配对交易/PCA 篮子套利的**上层组合构建**——不仅做多个股/做空个股，还要控制整体的 Beta 和行业暴露。

### Beta 中性

**`compute_rolling_beta()`**

```python
beta_i = Cov(r_i, r_market) / Var(r_market)
```

用 60 日滚动窗口估计每只股票相对市场基准的 Beta。

**`build_portfolio()`**

```txt
多头：因子得分最高的 N 只（等权 +1/N）
空头：因子得分最低的 N 只（等权 -scale/N）
         |
         └─ scale = β_long / β_short
            使 Σw_i·β_i = 0（组合 Beta = 0）
```

| 场景 | Beta 中性的意义 |
| :--- | :--- |
| 市场上涨 | 多头赚（+）+ 空头亏（-）→ 抵消，组合不涨 |
| 市场下跌 | 多头亏 + 空头赚 → 抵消，组合不跌 |
| 个股 Alpha | 无论市场涨跌，Alpha 都是正贡献 |

**如果多空两腿的 Beta 符号相同**（都为正或都为负），则无法通过缩放使 Beta 为 0——这种情况下代码 **不使用 Beta 中性化**（`scale = 1.0`），因为数学上不可行。

---

### 行业中性

**`sector_neutralize()`**

行业内因子去均值：

```python
factor_demeaned = factor - groupby(sector).transform("mean")
```

为什么这样做？因为：

- 如果某行业整体资金流入（如银行板块集体净流入），因子值都高；不做行业中性化，多头会集中在一个行业
- 这实际上是**行业暴露**，不是真正的 Alpha
- 行业内去均值后，选的是"行业内部的相对强弱"

### 三种组合构建方式的对比

| 方式 | 操作 | 市场相关性 | 适用场景 |
| :--- | :--- | :---: | :--- |
| 原始多空 | 不做任何中性化 | 高 | 不适用（风险太大） |
| Beta 中性 | 调整空头规模使 Beta ≈ 0 | 低 | 有 Beta 估计误差但无行业分类时 |
| Beta + 行业中性 | 因子先去行业均值，再 Beta 中性 | 极低 | 有行业分类时的推荐方案 |

## 十、局限与边界

### 协整关系的时变性

EG 和 Johansen 检验假设协整关系在样本期内是恒定的，但现实并非如此。滚动对冲比率和滚动 OU 参数可以部分缓解这个问题，但无法完全解决。建议：

- 定期重新检验协整关系（如每季度）
- 设置协整关系失效的止损（若价差持续偏离超过 3 倍半衰期，手动平仓）

### 做空限制

国内股票市场**融券做空受限**，统计套利的做空腿在实际执行中可能无法完全实现。替代方案：

- 用股指期货替代做空腿（但需要匹配行业暴露）
- 使用行业 ETF 做空（通过融券 ETF 实现）
- 只做多低估股、不做空高估股（退化为因子选股，但失去了市场中性）

### PCA 的稳定性

PCA 估计对输入数据敏感。当板块内部结构发生变化（并购、退市、新股上市），PC1 的载荷分布会剧烈变动，残差信号可能失真。

### 数据质量问题

- 协整检验需要较长的价格历史（至少 1~2 年日线数据），次新股和近期退市股会被自动排除
- 前复权价格在分红/送股后可能会有跳跃，影响对冲比率估计

### 容量限制

统计套利策略通常需要在多只股票上同时建仓和操作，资金规模过大时：

- 多腿同时建仓的冲击成本显著
- 小市值股票的流动性不足以支撑大单
- 配对交易需要同步执行两条腿，滑点风险高于单边交易

### 与 ML Alpha 策略的关系

| 维度 | 统计套利 | ML Alpha |
| :--- | :--- | :--- |
| 信号来源 | 价差均值回归（统计关系） | 多因子非线性组合（预测关系） |
| 市场暴露 | 市场中性（Beta ≈ 0） | 纯多头选股（Beta > 0） |
| 持仓方式 | 多空双边持仓 | 纯多头 Top N 等权 |
| 换手率 | 中等（价差偏离时触发） | 高（每月调仓） |
| 容量 | 低（多空同步执行难度大） | 中等 |
| 适用资金 | 小规模资金 | 中等规模 |
