## 一、为什么从乘法链改为加权求和

原有仓位计算：

$$\text{仓位} = \text{regime\_scale} \times \text{vol\_scale} \times \text{macro\_multiplier}$$

乘法链的问题：

- **极端放大**：某一信号极低（如 BEAR 状态下 `regime_scale=0.2`），其他信号无论多高都无法弥补，最终仓位极度压缩
- **难以解释**：三个乘数同时变化时，无法直觉判断各信号的独立贡献
- **扩展代价大**：新增第四个信号后，乘法链的波动幅度再度放大

改为**加权求和**后：

$$\text{仓位} = \sum_{i} w_i \cdot s_i, \quad \sum w_i = 1$$

每个信号独立贡献，权重之和为 1，仓位是各信号的线性组合，直觉清晰，且新增信号只需分配权重，不破坏已有逻辑。

## 二、四信号融合（`quant/advisor/position.py`）

### 信号归一化到 [0, 1]

| 信号 | 原始来源 | 归一化方式 | 取值范围 |
| --- | --- | --- | --- |
| `regime_signal` | Regime 状态 | BULL→1.0 / RANGE→0.6 / BEAR→0.2 | {0.2, 0.6, 1.0} |
| `vol_signal` | 波动率目标法 | `clip(target_vol / realized_vol, 0, 1)` | [0, 1] |
| `macro_signal` | 宏观景气 z-score | `clip((score + 2) / 4, 0, 1)` | [0, 1] |
| `sector_signal` | 行业轮动（待接入） | 占位值 0.5 | {0.5} |

归一化使四个信号处于同一量纲，权重的含义因此清晰：`regime` 权重 0.4 意味着市场状态贡献 40% 的仓位判断。

### 权重配置（`SignalWeightsConfig`）

`quant/config.py` 中新增：

```python
@dataclass
class SignalWeightsConfig:
    regime: float = 0.4
    vol: float = 0.3
    macro: float = 0.2
    sector: float = 0.1
```

对应 `configs/default.yaml`：

```yaml
signal_weights:
  regime: 0.4
  vol: 0.3
  macro: 0.2
  sector: 0.1
```

Dashboard 策略页的滑条可实时调整权重，调整后自动归一化，保证总权重恒为 1。

### 零权重的处理

当某个信号的权重为 0 时，直接以零序列替代计算结果：

```python
position = sum(
    s if coef > 0 else pd.Series(0.0, index=close.index)
    for coef, s in zip([w.regime, w.vol, w.macro, w.sector], weighted)
).clip(min_pos, max_pos)
```

这样避免 `0.0 * NaN = NaN` 的传播——信号数据缺失时，零权重信号不会污染求和结果。

## 三、组合优化器（`quant/portfolio/optimizer.py`）

统一接口：输入年化 `mu`（预期收益向量）和 `cov`（协方差矩阵），返回权重向量 `w`（sum=1）。

### 等权（Equal Weight）

$$w_i = \frac{1}{n}$$

零参数基准策略。实践中常被用作比较基线——若 MVO 的夏普比没有显著超过等权，说明协方差估计的噪声已经抵消了优化收益。

### 均值方差优化（MVO）

$$\min_w \quad \frac{\lambda}{2} w^\top \Sigma w - \mu^\top w \quad \text{s.t.} \quad \sum w_i = 1,\; w_i \in [w_{\min}, w_{\max}]$$

用 scipy SLSQP 求解，**显式提供解析梯度**：

$$\nabla f(w) = \lambda \Sigma w - \mu$$

**为什么不用数值梯度？**  
scipy 的数值差分梯度在约束边界附近会将微扰后的点传入目标函数，有时传入 0-d 数组（标量而非向量），导致 `w @ cov @ w` 中 matmul 报 `Input operand does not have enough dimensions`。显式传入 `jac=` 完全绕过这一问题。

### 风险平价（Risk Parity）

目标：所有资产风险贡献相等：

$$RC_i = w_i \cdot (\Sigma w)_i = \frac{1}{n} \cdot w^\top \Sigma w$$

采用 **Spinu (2013) 循环坐标下降**，每次只对单个 $w_i$ 求解二次方程：

$$\Sigma_{ii} w_i^2 + a_i w_i - c = 0$$

其中 $a_i = (\Sigma w)_i - \Sigma_{ii} w_i$，$c = \frac{1}{n} w^\top \Sigma w$，取正根：

$$w_i = \frac{-a_i + \sqrt{a_i^2 + 4\Sigma_{ii}c}}{2\Sigma_{ii}}$$

迭代至 $\max_i |w_i - w_i^{\text{prev}}| < 10^{-9}$ 收敛。

**为什么不用 SLSQP 做风险平价？**  
风险平价目标函数在 $w_i \to 0$ 时出现数值奇点，SLSQP 的有限差分梯度在此处不稳定，会向内层函数传入 0-d 数组导致 matmul 报错。Spinu 算法完全解析，每步只解一个二次方程，无需 scipy，比 SLSQP 快且稳定。

### 行业暴露约束（sector_constraints）

MVO 支持可选的行业暴露约束，通过 `sector_constraints` 参数传入：

```python
sector_constraints: list[tuple[np.ndarray, float, float]] | None = None
# 每项格式：(sector_vec, low, high)
# sector_vec: shape (n,) 的 0/1 向量，标记哪些资产属于该行业
```

内部转换为 SLSQP 不等式约束：

```txt
low  ≤ sector_vec · w ≤ high
```

调用示例（4 只资产，前两只为权益类，行业暴露上限 50%）：

```python
sector_vec = np.array([1.0, 1.0, 0.0, 0.0])
w = optimize(mu, cov, method="mvo", sector_constraints=[(sector_vec, 0.0, 0.5)])
```

可同时传入多个行业约束，每个约束独立生效。

### Black-Litterman

BL 模型在均衡收益（市值隐含）的基础上，融合主观观点，输出后验预期收益 μ_BL，再传入 MVO。

**三个输入：**

| 参数 | 含义 | 示例 |
| --- | --- | --- |
| `w_market` | 市值权重（均衡参考点） | `[0.5, 0.3, 0.2]` |
| `P` | 观点矩阵，每行一个观点，shape (k, n) | `[[1, -1, 0]]`（F0 vs F1 相对观点） |
| `Q` | 观点收益向量，shape (k,) | `[0.05]`（F0 比 F1 年化多 5%） |

**推导过程：**

1. 均衡隐含收益：$\pi = \lambda \Sigma w_{\text{mkt}}$
2. 观点误差协方差（默认）：$\Omega = \text{diag}(P \cdot \tau\Sigma \cdot P^\top)$
3. BL 后验：

$$\mu_{\text{BL}} = \left[(\tau\Sigma)^{-1} + P^\top \Omega^{-1} P\right]^{-1} \left[(\tau\Sigma)^{-1} \pi + P^\top \Omega^{-1} Q\right]$$

**直觉解释：** μ_BL 是均衡收益 π 和观点 Q 的加权平均——当观点很确定（Ω 小）时，μ_BL 向 Q 偏移；当观点很模糊时，μ_BL 接近 π。`tau` 控制对先验的整体不确定程度，通常取 0.01～0.10。

**完整调用示例：**

```python
from quant.portfolio.optimizer import black_litterman, optimize

w_mkt = np.array([0.5, 0.3, 0.2])
P = np.array([[1.0, -1.0, 0.0]])   # 相对观点：F0 优于 F1
Q = np.array([0.05])               # F0 年化多 5%

mu_bl = black_litterman(cov, w_mkt, P, Q)
w = optimize(mu_bl, cov, method="mvo", w_max=0.6)
```

diff_amt > 0                   →  🟢 建议加仓
diff_amt < 0                   →  🔴 建议减仓

## 五、学习要点

### 1. 加权求和 vs 乘法链

乘法链有"短板效应"——最弱的一项主导结果。加权求和每个信号独立贡献，可解释性更好。选哪种结构取决于业务语义：若信号是"必要条件"（某一项极差就应极度压仓），乘法更合适；若信号是"多角度证据"（每项都是部分依据），加权求和更合适。

### 2. SLSQP 解析梯度

scipy SLSQP 默认用有限差分估计梯度，在约束边界和数值奇点附近行为不稳定。显式传入 `jac=` 是提升 SLSQP 稳健性的标准做法，尤其是约束多、维度高时。

### 3. Spinu 算法

风险平价的经典数值解法（2013），通过坐标下降将多变量非线性问题分解为逐个变量的二次方程，每步有闭式解，无需外部优化器。比 SLSQP + 数值梯度快 3～5 倍，收敛更稳定。

### 4. Streamlit 模块缓存

`@st.cache_data` 缓存的是函数返回值，但 Python 模块本身由解释器缓存。修改 `quant/` 中的 `.py` 文件后，Streamlit 热重载只更新 `pages/` 脚本，不会重新导入 `quant/` 模块——需重启 Streamlit 服务器才能让底层模块变更生效。

### 5. 零权重信号的 NaN 传播

`0.0 * NaN` 在 pandas/numpy 中仍为 `NaN`，不是 0。若某信号数据缺失且权重为 0，不能期望乘法自动消除 NaN，需显式替换为零序列。
