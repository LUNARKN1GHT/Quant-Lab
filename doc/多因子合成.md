# 多因子合成

**代码**：[quant/factor/combine.py](../quant/factor/combine.py)

## 模块功能

单个因子的 IC 通常在 0.03 ~ 0.07 之间，噪声很大。多因子合成的目标是：**通过组合多个相关性低的因子，在保留有效信号的同时降低单因子的噪声**。

不合成直接用的问题：任何单因子都有失效期。纯动量因子在市场反转时亏损严重，纯价值因子在成长股行情中连续跑输。合成因子通过组合不同风格的因子，使策略不会在某类行情中完全失灵。

---

## 两种合成方式

### 1. 等权合成（`equal_weight`）

```python
def equal_weight(factors: pd.DataFrame) -> pd.Series:
    return factors.mean(axis=1)
```

对所有因子取截面均值，每个因子权重 = 1 / N。

**优点**：
- 实现最简单，无需历史数据
- 对估计误差最鲁棒——权重不依赖任何历史统计量，因此不存在权重估计偏差
- 研究阶段的快速验证首选

**缺点**：
- 不区分因子质量——IC=0.06 的强因子和 IC=0.01 的弱因子权重相同
- 在因子数量不平衡时（如 3 个动量类 + 1 个价值类），隐含了对动量的超配

---

### 2. IC 加权合成（`ic_weight`）

```python
def ic_weight(factors: pd.DataFrame, ic_scores: pd.Series) -> pd.Series:
    weights = ic_scores / ic_scores.sum()
    return factors.mul(weights, axis=1).sum(axis=1)
```

以各因子的历史 IC（或 ICIR）作为权重，归一化后加权求和。

**直觉**：IC 越高的因子，历史上对下期收益的预测能力越强，理应占更大的权重。

**两个关键问题**：

| 问题 | 说明 |
| :--- | :--- |
| 用 IC 还是 ICIR？ | IC 是平均预测能力，ICIR 是 IC 的信噪比（均值/标准差）。ICIR 更好：一个 IC 均值高但方差大的因子，实际中稳定性差，权重应打折 |
| 用多长窗口计算历史 IC？ | 窗口太短（如 3 个月）会过度追逐近期表现的因子，导致权重频繁切换；窗口太长（如 3 年）可能包含已失效的因子。通常用 12 个月滚动 ICIR |

**缺点**：
- 需要足够的历史数据（至少 12 个月）才能得到稳定的权重估计
- 权重对历史 IC 计算方式敏感（截面还是时序、用哪段样本）
- 存在过拟合风险——历史 IC 最高的因子可能是噪声因子，在样本外失效

## 合成前的标准化

合成前，每个因子需要做**截面标准化**（z-score），否则量级不同的因子会相互污染：

```txt
原始因子（未标准化）：
  市净率：范围 1~8
  换手率：范围 0.1%~15%
  动量（20日）：范围 -30%~+30%

直接平均 → 换手率被完全淹没在市净率的量级中
```

标准化公式（截面 z-score）：

$$z_{i,t} = \frac{f_{i,t} - \mu_t}{\sigma_t}$$

其中 $\mu_t$ 和 $\sigma_t$ 是第 $t$ 日截面上所有股票该因子的均值和标准差。标准化后均值为 0、标准差为 1，各因子量纲统一。

---

## 方向对齐

合成前还需确认每个因子的**方向一致性**——即因子值越大，预期收益越高（或越低）。方向不一致的因子直接加权会相互抵消。

常见因子方向：

| 因子 | 方向 | 含义 |
| :---: | :---: | :--- |
| 动量（20日涨幅） | 正向 | 值越大，近期强势，预期继续上涨 |
| 市净率（PB） | 反向 | PB 越低，价值越低估，需乘 -1 后合成 |
| 换手率 | 负向 | 换手率过高通常是追高信号，预期反转 |

在代码中，反向因子在传入 `combine.py` 前已做取负（或在因子计算模块中取倒数），`combine.py` 默认接收方向统一为"值越大越好"的因子矩阵。

## 扩展方向：PCA 合成

当前代码只实现了等权和 IC 加权，第三种常见方法是 **PCA 合成**：

```txt
因子矩阵（N股 × K因子）
    ↓
PCA 降维
    ↓
第一主成分 PC1：解释方差最大的方向
    ↓
以 PC1 的载荷作为权重，加权合成
```

PCA 合成的出发点是：当多个因子高度相关时（如多个动量类因子），IC 加权会把大量权重集中在同一类因子上。PCA 通过正交化消除相关性，确保合成因子捕捉到不同的信息维度。

实践中 PCA 合成的工程成本较高（需要滚动 PCA + 符号对齐），且 IC 加权已经能满足大多数使用场景，因此当前版本暂未实现。

---

## 局限与边界

- **合成不能拯救无效因子**：如果某个因子历史 IC ≈ 0，无论用哪种合成方式，它对综合因子的贡献都约等于噪声
- **权重估计的样本外稳定性**：IC 加权的权重基于历史数据，市场风格切换时权重可能滞后
- **等权 ≠ 劣等**：大量实证研究表明，等权合成因为规避了权重估计误差，样本外表现往往不亚于复杂加权方法

## 与其他模块的关系

- **上游**：`quant/factor/` 下各因子模块（`momentum.py`、`reversal.py`、`volatility.py` 等）产出单因子值；`quant/factor/ic_analysis.py` 提供历史 IC / ICIR 作为 IC 加权的权重输入
- **下游**：合成因子传入 `quant/strategy/factor_strategy.py`，按截面排名做 Top N 选股
- **与 ML Alpha 的关系**：合成因子是线性加权，ML Alpha（LightGBM）是非线性组合。合成因子可以作为 ML Alpha 的输入特征，也可以作为基准对比 ML Alpha 的增量价值
