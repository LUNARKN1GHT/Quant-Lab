# 风险指标体系

**代码**：[quant/risk/metrics.py](../quant/risk/metrics.py) · [quant/risk/report.py](../quant/risk/report.py) · [quant/risk/attribution.py](../quant/risk/attribution.py)

## 模块功能

提供策略评估所需的绩效与风险度量函数。输入统一为日度收益率序列，输出单一数值或序列，与回测引擎解耦，也可单独用于分析任意收益流。`attribution.py` 额外提供 Brinson 归因，将超额收益拆解到行业维度。

---

## 核心指标详解

### Sharpe Ratio（夏普比率）

$$\text{Sharpe} = \frac{\overline{r - r_f}}{\sigma(r - r_f)} \times \sqrt{252}$$

衡量**单位总波动换来多少超额收益**。分子是策略相对无风险利率的日均超额收益，分母是这个超额收益的标准差，乘以 $\sqrt{252}$ 将日度结果年化。

> 为什么乘 $\sqrt{252}$ 而不是 $252$？  
> 因为均值按 $\times 252$ 年化，标准差按 $\times \sqrt{252}$ 年化，两者相除之后只剩 $\times \sqrt{252}$。

**使用时的注意点**：

- `risk_free` 参数应传**日度**无风险利率，如年化 3% 对应 `0.03/252 ≈ 0.000119`。默认值为 0，相当于以现金为基准。
- Sharpe 对上行波动和下行波动一视同仁——一只每天涨 0.5% 但波动极大的策略，Sharpe 不一定高。
- 一般认为年化 Sharpe > 1 才算可用，> 2 属于优秀。

---

### Sortino Ratio（索提诺比率）

$$\text{Sortino} = \frac{\overline{r - r_f}}{\sigma_{\text{downside}}} \times \sqrt{252}$$

与 Sharpe 的唯一区别：分母只统计**负收益日**的标准差（下行标准差），不惩罚上行波动。对趋势跟踪策略更友好——策略有时大涨会拉高 Sharpe 的分母，但 Sortino 不会因此变差。

**容易踩的坑**：  
如果策略几乎从不亏损（如短债基金），负收益样本趋近于 0，`downside.std()` 会极小甚至为 NaN，导致 Sortino 爆掉。策略运行时间短、亏损天数少时慎用。

---

### 最大回撤（Max Drawdown）

$$\text{MDD} = \min_t \frac{\text{NAV}_t - \max_{s \leq t} \text{NAV}_s}{\max_{s \leq t} \text{NAV}_s}$$

净值从**历史峰值**跌到谷底的最大幅度，直观上是「如果你在最高点买入，最坏情况下亏了多少」。

代码返回**负数**，绝对值才是通常说的最大回撤。设计成负数是为了保持符号一致——回撤序列里任意一天的值都 ≤ 0，可以直接取 `.min()` 而不需要取反。

`drawdown_series()` 返回逐日回撤曲线（用于画水下图），`underwater_stats()` 汇总最长连续水下天数和平均回撤深度。

**与 Calmar 的关系**：最大回撤是 Calmar 的分母，两者搭配使用——MDD 告诉你最坏的历史经历，Calmar 告诉你收益是否足够补偿这个风险。

---

### Calmar Ratio（卡玛比率）

$$\text{Calmar} = \frac{\text{年化收益率}}{|\text{最大回撤}|}$$

值越高，说明单位回撤代价换取的年化收益越多。适合评估**趋势跟踪**类策略，因为这类策略的核心优势就是控制回撤——收益平平但回撤极小的策略，Calmar 可以很高。

与 Sharpe 的区别：Sharpe 用波动率衡量风险（对称），Calmar 用最大回撤（只看最坏情形）。两者侧重不同，一般同时报告。

---

### VaR（Value at Risk，风险价值）

$$\text{VaR}_{95\%} = Q_{5\%}(\text{日度收益})$$

历史最差 5% 情形的单日收益分位数，回答「**正常倒霉能亏多少**」。返回负数，绝对值是单日最大亏损的历史估计值。

本项目使用**历史模拟法**（直接取分位数），计算简单但依赖历史分布不变的假设，极端黑天鹅事件（超出历史范围）无法捕捉。

---

### CVaR（Conditional VaR，条件风险价值）

$$\text{CVaR} = \mathbb{E}[r \mid r \leq \text{VaR}]$$

VaR 以下所有亏损日的**平均值**，又称 Expected Shortfall（ES）。回答「**极端情形平均亏多少**」，比 VaR 更完整地刻画尾部风险。

VaR 的问题：只说"5% 最坏情形的临界点在哪"，但不管临界点以下的分布是胖尾还是细尾。CVaR 把临界点以下的均值全部纳入，尾部越胖、CVaR 与 VaR 的差距越大。

---

### Beta 与 Alpha（CAPM 框架）

$$r_t = \alpha + \beta \cdot r_{m,t} + \epsilon_t$$

用 OLS 将策略日度收益对市场收益做线性回归：

- **Beta（β）**：策略对市场的敏感程度。β = 1.2 意味着市场涨 1%，策略预期涨 1.2%；跌市同样放大。
- **Alpha（α）**：回归截距，代表在扣除市场暴露后策略剩余的超额收益来源，即"选股/择时能力"。

**局限**：  
代码用全样本 OLS 估计，对窗口选取和异常值敏感，适合粗略判断暴露方向，不适合精细的风险归因（那需要 Barra 多因子模型）。

---

### Brinson 归因

将组合相对基准的超额收益拆成三部分：

| 效应 | 公式 | 含义 |
| --- | --- | --- |
| 配置效应 | $(w_p - w_b) \times (r_b^i - R_b)$ | 超配/低配某行业的决策本身带来多少 |
| 选股效应 | $w_b \times (r_p^i - r_b^i)$ | 在同一行业内，组合收益超越基准多少 |
| 交互效应 | $(w_p - w_b) \times (r_p^i - r_b^i)$ | 超配且选股也超额的联合贡献 |

三者之和 = 组合总超额收益。

代码是**单期截面**实现，多期分析需要在调用方按日期循环，再对各期结果加权聚合（通常用各期基准收益作为权重）。

## 统一风险报告（`risk_report()`）

`metrics.py` 提供原子指标函数，但实际使用时常常需要一组指标同时输出。`risk_report()` 将常用指标打包成结构化字典，作为 Dashboard 与脚本的统一入口：

```python
from quant.risk.report import risk_report

report = risk_report(returns, market_returns=csi300_ret)
# {
#   "annual_return": 0.18, "annual_vol": 0.22,
#   "sharpe": 1.05, "sortino": 1.42, "calmar": 0.83,
#   "var_95": -0.025, "cvar_95": -0.038,
#   "max_drawdown": -0.21,
#   "max_underwater_days": 87, "avg_drawdown": -0.06,
#   "drawdown_series": <pd.Series>,
#   "beta": 0.92, "alpha_annual": 0.04,  # 传入 market_returns 时
# }
```

设计上有两点选择：

- **`market_returns` 可选**：未传入时跳过 Beta / Alpha，避免强制依赖基准数据；传入后内部按 `r.reindex(mkt.index).dropna()` 对齐再回归
- **保留 `drawdown_series` 原始序列**：Dashboard 直接拿去绘制水下曲线，避免重复计算

`risk_free` 接日度无风险利率（年化 3% 传 `0.03/252`），与底层 `sharpe()` / `sortino()` 参数语义一致。

---

## 实现要点

- 所有年化系数统一用 252 个交易日。
- `max_drawdown` 返回负数，`abs()` 后才是通常表述的回撤幅度；`calmar` 内部已处理。
- `underwater_stats` 用 Python 循环统计连续水下天数，数据量大时可改为 `groupby` 方案。
- Brinson 归因依赖明确的行业分类，输入的 `portfolio_weights` 和 `benchmark_weights` 的 index 必须对齐。

---

## 局限与边界

- 所有函数均假设输入为**日度**收益序列，月度/年度数据直接传入会导致年化系数错误。
- Sharpe / Sortino 对正态分布假设敏感，收益分布厚尾时会高估策略稳定性。
- VaR / CVaR 基于历史模拟法，极端黑天鹅事件（历史从未发生过的情形）无法反映。
- Brinson 归因依赖明确的行业分类，适合有基准对标的组合，不适合纯多头因子策略。
