# 宏观因子接入

**代码**：[quant/macro/loader.py](../quant/macro/loader.py) · [quant/macro/indicators.py](../quant/macro/indicators.py)

## 模块功能

将宏观经济指标（PMI、M2、国债收益率、CPI）转化为可量化的信号，用于两个目的：

1. **宏观景气乘数**：合成单一的 `macro_score`，作为 `advisor/position.py` 三层仓位乘数中的第三层，在宏观环境收紧时压缩持仓
2. **滞后相关性分析**：帮助理解各宏观指标对大盘的领先/滞后效应，是研究性分析工具

---

## 四个宏观指标

| 指标 | 来源 | 频率 | 对市场的传导逻辑 |
| :--- | :--- | :---: | :--- |
| PMI（制造业采购经理人指数） | akshare 官方制造业PMI | 月频 | 领先指标，PMI > 50 扩张，预期企业盈利改善 |
| M2 同比增速 | akshare 货币供应量 | 月频 | 流动性代理，M2 加速扩张 → 资金充裕 → 利好股市 |
| 十年期国债收益率 | akshare 中美国债 | 日频 | 无风险利率，利率上升 → 估值压制，对股市负面 |
| CPI 同比 | akshare CPI年率 | 月频 | 通胀代理，温和通胀是中性信号，恶性通胀预期加息 |

## 数据加载：本地 CSV 缓存

**`_load_or_fetch()`**

```txt
data/macro/{name}.csv 存在？
    是 → 直接读取，无网络请求
    否 → 调用 akshare 拉取，写入 CSV，返回数据
```

这样处理的原因：akshare 的宏观接口（PMI、M2）响应慢且偶发超时，每次启动都重新请求会降低系统可用性。CSV 缓存后，正常运行时完全离线，网络故障不影响分析。

**代理环境处理**：

```python
os.environ["no_proxy"] = "*"
```

部分系统代理会拦截 akshare 对国内接口的 HTTP 请求。设置 `no_proxy=*` 使 akshare 的请求绕过代理，直连目标服务器。

## 滞后相关性分析

**`calc_lag_corr()`**

宏观指标和大盘收益率之间存在**时间上的领先/滞后关系**——PMI 上升后，企业盈利改善往往需要 1~3 个月才体现在股价上。直接计算当期相关性可能接近零，但某个滞后期（如 lag=2 个月）相关性可能最高。

```txt
计算方式：
  for lag in 0~6:
    将宏观指标向前移动 lag 个月（shift(lag)）
    与同期大盘月收益率计算 Pearson 相关系数
  绘制 "相关系数 vs 滞后期" 曲线，找最优领先窗口
```

日频大盘收益率先转换为月频（`resample("ME").prod()`，复合收益）后，再与月频宏观指标对齐。

**结果解读示例**：

```txt
PMI 的滞后相关性曲线：
  lag=0:  corr = 0.12
  lag=1:  corr = 0.21
  lag=2:  corr = 0.31  ← 最优领先期
  lag=3:  corr = 0.18
  lag=4:  corr = 0.09
```

lag=2 时相关性最高，说明 PMI 领先大盘约 2 个月——在构造景气指数时，PMI 信号应滞后 2 个月输入，或者说当月 PMI 对 2 个月后的大盘有预测意义。

## 合成景气指数

**`composite_index()`**

```txt
各指标 z-score 标准化（消除量纲差异）
    ↓
乘以方向系数（经济扩张时+1，利率上升取-1）
    ↓
等权平均 → macro_score
    ↓
月频前向填充到日频（ffill）
```

**方向系数**：

| 指标 | 方向系数 | 原因 |
| :---: | :---: | :--- |
| PMI | +1 | PMI 越高，经济越扩张，利好市场 |
| M2 同比 | +1 | M2 越高，流动性越充裕，利好市场 |
| 国债收益率 | **-1** | 利率越高，估值越受压制，负向关系 |
| CPI 同比 | +1 | 温和通胀对应经济扩张，整体正向（但极端高通胀除外） |

```txt
macro_score > 0：宏观偏扩张 → macro_multiplier > 1（仓位放大）
macro_score < 0：宏观偏收缩 → macro_multiplier < 1（仓位压缩）
```

**与仓位的映射（`advisor/position.py`）**：

$$\text{macro\_multiplier} = \text{clip}\left(\frac{\text{macro\_score} - (-2)}{2 - (-2)}, 0, 1\right) \times 0.8 + 0.6$$

宏观 z-score 在 [-2, 2] 范围内线性映射到 [0.6, 1.4]，超出范围截断。

## 局限与边界

- **月频数据的发布滞后**：PMI、M2、CPI 都是月末或次月初发布，存在 1~4 周的发布滞后。策略中已用"前向填充"处理日频对齐，但第一个交易日能用到的宏观数据实际上是上个月的
- **CPI 的双向性**：CPI 在温和通胀区间（1%~3%）对市场偏正面，但恶性通胀（>5%）预期加息，对市场是负面的。当前合成用的是线性方向系数，无法捕捉这种非线性关系
- **指标选择的主观性**：当前四个指标是经验选择，并非系统筛选的结果。换不同的指标（如信贷增速、工业增加值），合成结果会有差异
- **国内宏观数据的修订性**：部分宏观统计指标存在事后修订，历史回测时用的是"当时发布值"还是"修订后值"会影响结论，akshare 拉取的数据通常是最新修订版

## 与其他模块的关系

- **下游**：`quant/advisor/position.py` 消费 `macro_score`，转化为仓位乘数的第三层；`pages/1_position_advise.py` 在 Dashboard 展示宏观景气走势
- **与 Regime 的关系**：Regime（`quant/regime/`）是技术指标驱动的短期市场状态判断（周~月级别），宏观因子是基本面驱动的中长期景气判断（季度级别）。两者分别捕捉不同时间尺度的风险，三层乘数相乘实现多尺度控仓
- **脚本**：`scripts/research_macro.py` 展示各指标的滞后相关性曲线与景气指数历史走势
